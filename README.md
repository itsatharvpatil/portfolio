# Atharv Patil — Portfolio

Static, responsive portfolio ready for GitHub Pages.

## Publish

1. Create a repository named `YOURUSERNAME.github.io` (or use an existing repository configured for Pages).
2. Upload everything in this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
4. Open your GitHub Pages URL.

No build step or framework is required.

## Files

- `index.html` — portfolio content and semantic structure
- `styles.css` — responsive visual system, light/dark themes and components
- `script.js` — navigation, theme persistence, filters, scrollspy, animations and ventilator replay
- `assets/Atharv_Patil_CV.pdf` — CV linked from the site
- `assets/favicon.svg` — favicon
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Notes

The website contains only links and claims supported by the supplied CV/reference material and repository information.
Schematic graphics are explicitly described as schematic rather than being presented as real production or patient data.
